// sobre-mi

Una sola persona, de principio a fin.

Estudio Ingeniería Informática en la UPC (Facultat d'Informàtica de Barcelona) y llevo años convirtiendo ideas en software que funciona. Trabajo solo y de forma directa: hablas conmigo, no con un intermediario, y sé exactamente qué hay detrás de cada línea de código de tu proyecto.

Si buscas a alguien que entienda tu problema, construya la solución completa y te la deje funcionando en producción, ese soy yo.

// proyectos

Algo de lo que he construido.

Proyectos reales, de la idea al código funcionando. Cada uno cuenta qué problema resuelve.

sistema-trafico/★ Premio UPC 2024

Sistema inteligente de gestión de tráfico

Sistema que integra sensores y algoritmos para detectar y gestionar el tráfico de vehículos en tiempo real. Fue mi trabajo de investigación de bachillerato y ganó el Premio UPC de Arquitectura, Ingeniería, Ciencias y Tecnología (25.ª edición, 2024).

futtrainer/

FutTrainer

Aplicación completa para entrenadores de fútbol: ayuda a planificar, organizar y gestionar el trabajo del equipo desde un solo sitio. Un proyecto en el que uní mi lado técnico con lo que conozco del fútbol de primera mano.

React Node Express

lumo/

Lumo

Coach de hábitos conversacional: ayuda a crear y mantener buenos hábitos a través de una conversación natural, en lugar de otra lista de tareas más. Frontend, backend y lógica de conversación, todo integrado.

React Node API IA
generador-fichas/

Generador de exámenes y fichas

Software que crea exámenes y fichas de ejercicios de forma automática, ahorrando horas de preparación. Pensado para profesores y academias que necesitan generar material a medida de forma rápida.
